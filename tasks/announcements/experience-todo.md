## المرحلة 1: الإرسال

### المهمة 1: تعريف عقد العميل ودوال API

**الوصف:** تعريف أنواع الإعلانات والإيصال والعناصر المعلقة للمتصفح، وإضافة دوال طلب موحدة للإرسال وجلب المعلّقات وإغلاقها دون استيراد كود الخادم إلى العميل.

**معايير القبول:**
- [x] تمثل الأنواع الثلاثة وبيانات المرسل والغرفة وcursor وفق استجابات API الحالية.
- [x] ترسل دوال العميل JSON و`Idempotency-Key` للإرسال، وتعرض أخطاء HTTP بوضوح دون اعتبار الفشل نجاحًا.
- [x] تغطي الاختبارات نجاح الاستجابات وأخطاء HTTP والتحقق من حدود جسم الطلب.

**التحقق:**
- [x] تشغيل اختبار عقد العميل الجديد مع مجموعة الاختبارات.
- [x] نجاح TypeScript وESLint للملفات المضافة.

**الاعتماديات:** لا يوجد.  
**الملفات المحتملة:**
- `src/lib/announcements.ts`
- `tests/announcementsClient.test.ts`
**النطاق المقدر:** صغير.

### المهمة 2: إضافة إرسال الإعلان إلى الإعدادات

**الوصف:** إضافة زر إرسال مشروط بامتلاك صلاحية نوع فعالة واحدة على الأقل، ونافذة تتيح اختيار نوع مسموح ووجهة/غرفة عند الحاجة وكتابة نص الإعلان ثم إرساله.

**معايير القبول:**
- [x] لا يظهر الزر عند غياب صلاحيات جميع الأنواع؛ ولا تعرض النافذة إلا الأنواع المسموحة للحساب.
- [x] يفرض النموذج النص غير الفارغ وحد 1000 وحدة نصية، ويطلب غرفة عند نوع الغرفة، ويمنع الإرسال المكرر أثناء الطلب.
- [x] تعرض حالات النجاح والفشل بوضوح، وتبقي المدخلات عند الفشل وتغلق النافذة بعد نجاح الإرسال.

**التحقق:**
- [x] نجاح الاختبارات والبناء وTypeScript وESLint للملفات الجديدة.
- [x] استخدام Dialog وحقول وعناصر تحكم مسماة وقابلة للوحة المفاتيح.

**الاعتماديات:** المهمة 1.  
**الملفات المحتملة:**
- `src/components/chat/SettingsPanel.tsx`
- `src/components/chat/AnnouncementComposer.tsx`
- `src/lib/announcements.ts`
- اختبار مساعدات النموذج عند الحاجة.
**النطاق المقدر:** متوسط.

## المرحلة 2: الاستلام والعرض

### المهمة 3: مزامنة قائمة الإعلانات المعلقة

**الوصف:** إنشاء منطق استلام مركزي يحمّل جميع صفحات الإعلانات المعلقة، ويستمع لأحداث الإنشاء والإغلاق، ويدمجها دون تكرار أو فقد عند تزامن الحدث مع GET.

**معايير القبول:**
- [x] يبدأ الاستماع قبل الجلب، ويدمج نتائج الصفحات والأحداث حسب معرف الإعلان مع الحفاظ على ترتيب FIFO.
- [x] يزيل الإعلانات المغلقة من اتصال آخر ويعيد تحميل القائمة عند الاتصال/إعادة الاتصال.
- [x] تغطي الاختبارات الدمج والترتيب والتكرار والصفحات ودورات cursor.

**التحقق:**
- [x] نجاح اختبارات منطق القائمة وTypeScript وESLint للملفات الجديدة.

**الاعتماديات:** المهمة 1.  
**الملفات المحتملة:**
- `src/lib/announcementInbox.ts`
- `src/hooks/useAnnouncementInbox.ts`
- `src/lib/announcements.ts`
- `tests/announcementInbox.test.ts`
**النطاق المقدر:** متوسط.

### المهمة 4: عرض الشريط العام وإغلاق الإعلان

**الوصف:** ربط قائمة الاستلام بمكوّن واحد على مستوى Dashboard يعرض الإعلان الحالي أعلى التطبيق ويتيح إغلاقه، مع إبقائه ثابتًا عند تغيير التبويب.

**الحالة:** اكتمل التنفيذ؛ التحقق التفاعلي النهائي ينتظر جلسة مستخدم مخول في المتصفح.

**معايير القبول:**
- [x] يعرض عنصرًا واحدًا في كل مرة مع النوع والمرسل وصورته والنص كنص عادي وزر X واضح.
- [x] يبقى الإعلان ظاهرًا حتى يطلب المستخدم إغلاقه؛ تزال النسخة المحلية بعد نجاح DELETE وتتزامن الإزالة لباقي الاتصالات.
- [x] لا يُقصى أو يُخفى الشريط عند تبديل التبويبات، ويظل مقروءًا وقابلًا للاستخدام بلوحة المفاتيح على المقاسات الصغيرة.

**التحقق:**
- [x] نجاح الاختبارات والبناء وTypeScript وESLint للملفات الجديدة.
- [ ] التحقق في المتصفح من وصول إعلان، التتابع، الإغلاق، وإعادة التحميل؛ تعذر ذلك لعدم توفر جلسة مخولّة.

**الاعتماديات:** المهمة 3.  
**الملفات المحتملة:**
- `src/pages/Dashboard.tsx`
- `src/components/chat/AnnouncementBanner.tsx`
- `src/hooks/useAnnouncementInbox.ts`
- `src/lib/announcements.ts`
**النطاق المقدر:** متوسط.

## المرحلة 3: التحقق النهائي

### المهمة 5: التحقق التكاملي النهائي

**الوصف:** التحقق من التجربة كاملةً في الاختبارات والبناء والمتصفح، ومعالجة أي عيب تكاملي ظهر في هذا النطاق فقط.

**معايير القبول:**
- [x] اجتازت مجموعة الاختبارات والبناء وفحص TypeScript.
- [x] اجتاز ESLint للملفات الجديدة؛ بقيت مخالفات أساس غير مرتبطة في `SettingsPanel.tsx` و`Dashboard.tsx` دون إصلاح.
- [ ] التحقق التفاعلي من الإرسال والاستلام والإغلاق في جلسة مستخدم مخول.

**التحقق:**
- [x] فتح التطبيق في المتصفح؛ ظهرت شاشة الدخول، ولم تتوفر جلسة مخولّة لإكمال تجربة الإعلانات.
- [x] ظهرت تحذيرات React Router السابقة في شاشة الدخول؛ لم تظهر أخطاء JavaScript مرتبطة بتغييرات الإعلان.

**الاعتماديات:** المهمتان 2 و4.  
**الملفات المحتملة:** لا ملفات متوقعة؛ تقتصر التغييرات على إصلاحات لازمة ومباشرة ضمن النطاق.  
**النطاق المقدر:** صغير.
