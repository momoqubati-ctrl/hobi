# قائمة مهام: صلاحيات الإعلانات (`announcement-permissions`)

المواصفة: [SPEC-announcement-permissions.md](../../SPEC-announcement-permissions.md)  
الخطة: [plan.md](./plan.md)

## المرحلة 1: قواعد الصلاحيات والتخزين

- [x] **`announcement-permission-keys` — تعريف صلاحيات أنواع الإعلانات**
  - القبول: تعريف صلاحيات منفصلة للجميع وأصحاب الرتب والغرفة ضمن مجموعة واضحة؛ عدم إضافة أي منها إلى صلاحيات العضو الافتراضية؛ جعلها قابلة للتعديل عبر مصفوفة الرتب.
  - التحقق: اختبارات `node:test` تثبت ظهور الصلاحيات الثلاث في المجموعة، وأن كل مفتاح فعل `use` قابل للتعديل، وأنها غير ممنوحة افتراضيًا.
  - الملفات: `src/lib/chatFeaturePermissions.ts`, `tests/chatFeaturePermissions.test.ts`
  - الاعتماديات: لا يوجد.

- [x] **`announcement-role-limit-schema` — إضافة حصة يومية للرتبة**
  - القبول: إضافة عمود `announcement_daily_limit` من نوع integer افتراضيه 0، مع قيد 0–1000؛ تضمينه في إنشاء الجدول والترحيل الإضافي للجدول الحالي.
  - التحقق: اختبارات مخطط Drizzle والتحقق من أن الترحيل يستخدم إضافة آمنة قابلة لإعادة التشغيل؛ لا تُشغّل ترحيلات على قاعدة غير اختبارية.
  - الملفات: `server/db/schema.ts`, `server/db/migrate.ts`, `tests/announcementPermissionsSchema.test.ts`
  - الاعتماديات: لا يوجد.

## نقطة تحقق: الأساس

- [x] اختبارات صلاحيات الأنواع وقيمها الافتراضية تمر.
- [x] حقل الحصة وقيده الافتراضي ونطاقه ممثلون في المخطط والترحيل.

## المرحلة 2: واجهات الإدارة

- [x] **`announcement-policy-api` — قراءة وحفظ سياسة الإعلان**
  - القبول: إرجاع الحصة لكل رتبة؛ قبول تحديث الحصص اختياريًا في واجهة حفظ المصفوفة الحالية؛ رفض القيم غير الصحيحة وخارج 0–1000؛ حفظ الحصص والصلاحيات في معاملة واحدة؛ استمرار قبول الطلبات القديمة التي لا تحتوي الحصص.
  - التحقق: اختبارات API/خدمة تغطي المصادقة، منع تعديل رتبة المالك، الحدود 0 و1000، رفض -1 و1001 والقيم العشرية والنصية، وحفظًا ذريًا؛ ثم `npm test`.
  - الملفات: `server/routes/api/admin/roles.get.ts`, `server/routes/api/admin/permissions/bulk.post.ts`, `server/services/announcementRolePolicy.ts`, `tests/announcementPolicyApi.test.ts`
  - الاعتماديات: `announcement-permission-keys`, `announcement-role-limit-schema`.

- [ ] **`announcement-policy-editor` — تعديل الصلاحيات والحصة في المصفوفة**
  - القبول: عرض مفاتيح الأنواع الثلاثة في مجموعة الإعلانات؛ إظهار حقل حصة يومية صحيح للرتبة؛ حفظه مع الصلاحيات وعرض الأخطاء دون فقد التعديلات.
  - التحقق: `npm run build` وESLint للملفات المتغيرة؛ مراجعة الواجهة في مصفوفة صلاحيات الرتب.
  - الملفات: `src/components/admin/powers/PermissionsMatrix.tsx`, `src/components/admin/powers/permissionDefs.ts`
  - الاعتماديات: `announcement-permission-keys`, `announcement-policy-api`.
  - الحالة: التعديل والبناء مكتملان؛ المراجعة المرئية متعذرة حاليًا لأن المتصفح المدمج لا يثق بشهادة HTTPS المحلية.
